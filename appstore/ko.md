# 한국어 (ko)

## 프로모션 텍스트 (170자 이내)
해외여행 환율 계산은 TripRate! 19개 통화, 90일 그래프, 오프라인 지원.

## 설명 (4000자 이내)
TripRate - 여행자를 위한 환율 계산기

해외여행 중 "원화로 얼마지?" 궁금했던 적 있으신가요?
TripRate는 그 순간에 바로 답을 주는 환율 계산 앱입니다.

즉시 환율 계산
앱을 열고 금액을 입력하면 바로 계산. 복잡한 조작 없이 계산대나 환전소에서 빠르게 확인할 수 있습니다.

19개 주요 통화 지원
여행자가 자주 사용하는 통화를 엄선:
USD, EUR, GBP, JPY, CNY, KRW, THB, TWD, HKD, SGD, AUD, NZD, CAD, CHF, VND, PHP, MYR, IDR, RUB
아시아, 유럽, 북미, 오세아니아 인기 여행지 통화를 모두 지원합니다.

매일 업데이트되는 실시간 환율
신뢰할 수 있는 금융 데이터 소스에서 매일 자동 업데이트. 항상 최신 환율로 계산하세요. 마지막 업데이트 시간도 표시됩니다.

90일 환율 추이 차트
90일간의 환율 변동을 인터랙티브 차트로 확인. 최고가, 최저가, 현재 환율을 한눈에. 차트를 드래그하여 특정 날짜 환율도 확인 가능. 최적의 환전 타이밍을 찾아보세요.

오프라인 사용 가능
Wi-Fi 없이도 걱정 없음. 최신 환율을 캐시하여 인터넷 연결 없이도 계산 가능. 공항이나 해외에서도 안심.

수동 환율 모드
현지 환전소 환율로 계산하고 싶을 때 드럼롤 피커로 자유롭게 환율 설정. 시장 환율과 비교하여 유리한지 판단 가능.

이전 설정 자동 기억
통화 쌍과 계산 결과를 자동 저장. 앱을 다시 열어도 이전 상태가 그대로 복원됩니다.

12개 언어 지원
영어, 일본어, 한국어, 중국어 간체/번체, 태국어, 베트남어, 러시아어, 인도네시아어, 프랑스어, 독일어, 스페인어 지원.

깔끔한 디자인
통화 기호가 포함된 크고 선명한 숫자로 결과를 한눈에 확인. 심플한 계산기 인터페이스.

이런 분께 추천
- 해외여행이나 출장이 잦은 분
- 유학 중이거나 워킹홀리데이 중인 분
- 해외 온라인 쇼핑을 즐기는 분
- 환전소 방문 전 환율 확인이 필요한 분
